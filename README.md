# 📝 Khushi Blog

A responsive blog website built using **HTML5** and **CSS3**. The project features a clean and modern card-based layout to display blog posts with categories, author information, publication dates, and responsive design.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern card-based blog layout
- Blog categories and author information
- Clean and user-friendly interface
- Semantic HTML structure
- CSS Flexbox for responsive layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
